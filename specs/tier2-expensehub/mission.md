Mission

ExpenseHub is a small expense browser for people who want to know where it all goes.

"Know where it all goes."

Built as a learning project for course students exploring AI coding agents, ExpenseHub demonstrates the next step up from a single-page CRUD app: detail pages, URL parameters, category filtering, and proper server-side validation — including validating money — still FastAPI, Jinja2 templates, and Bootstrap CSS, still no database and no authentication, everything in memory.

The site stays small: a home page, an expense list with per-expense detail pages, category filtering with live totals, and an add-expense form that rejects bad input (including amounts that aren't positive numbers) and tells you exactly what you got wrong without losing what you typed.
