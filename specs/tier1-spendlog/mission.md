Mission

SpendLog is a tiny personal spending journal.

"Every penny, written down."

Built as a learning project for course students exploring AI coding agents, SpendLog demonstrates how to build a simple Python web application — FastAPI, Jinja2 templates, and Bootstrap CSS — without a database, without authentication, keeping everything in memory.

The site is deliberately small: a welcoming home page and a journal where you record what you spent and see the running total. No budgets, no accounts, no charts — an approachable example of web fundamentals with just enough real money math to keep it honest.
